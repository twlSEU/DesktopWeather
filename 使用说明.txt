桌面天气 Desktop Weather 1.3.1

启动软件
双击 release\DesktopWeather.exe，或双击 Start-Weather.cmd。
首次打开显示设置面板和实时预览，桌面特效默认关闭。
选择「雪花」，点击「开始下雪」，特效会出现在普通应用窗口上方。
点击季节卡片可直接改变正在播放的特效，无需重新开始。

五种季节特效
春 · 樱花：粉白花瓣缓慢飘落，随风摆动并轻轻旋转。
夏 · 萤火：黄绿色微光在屏幕上缓缓漂浮，每颗独立明暗闪烁。
夏 · 细雨：淡蓝色细雨快速落下，风力控制雨丝的倾斜和横向运动。
秋 · 落叶：暖色叶片随风飘落并旋转。
冬 · 雪花：白色雪点与少量六角雪花轻盈下落，带有远近景深。
远景和中景中，尺寸足够显示细节的雪花约有 30% 为六角形，比 1.3 的 20% 略多；近景仍使用柔和虚焦雪团。
雪花景深：远处小而清晰，中景轻微柔化，近处大而虚焦；近处雪花占少数。
大小、下落速度和风中摆动都与雪花距离关联，前景轻柔，远景层次丰富。
五种模式均显示在普通应用窗口上方，鼠标可自由穿透。

可调节内容
数量：50–1600，为所有所选屏幕的总数量；多屏按面积分配。
大小、运动速度、风向 / 风力、不透明度均实时生效。
萤火虫的速度控制漂浮速度，风力让微光缓缓偏移。
细雨的下落速度比雪花快；花瓣则下落得更缓慢。
「显示在所有屏幕」关闭时仅在主屏显示。
默认关闭「节能模式」，桌面特效跟随显示器刷新率。
开启「节能模式」时限制为 30 帧 / 秒，适合优先降低耗电的场景。
右上角 FPS 显示实际动画更新次数，不是设置的目标值。
预览区会按比例减少粒子，实际桌面数量以设置值为准。
「春樱」「夏夜」「夏雨」「秋风」「轻雪」「大雪」是六套可继续修改的预设。
点击季节卡片只改变模式，保留现有参数；点击预设会应用对应的数量、大小、速度等参数。
窗口较小时可滚动左侧面板查看下方设置。

停止和退出
「暂停」让当前特效停止运动，「继续」恢复运动。
「停止特效」移除全部特效窗口。
Ctrl + Alt + F12 可随时停止；快捷键被占用时面板会提示。
特效层透明、置顶、不获取焦点，鼠标可以继续点击下面的应用。
默认关闭设置面板后保留托盘图标，点击托盘图标可重新打开。
托盘右键菜单可切换天气、开始、暂停、停止或退出。
点击「退出软件」会完全退出并清除特效层。
再次运行软件会打开已运行的设置面板，不会创建重复实例。

设置保存
设置保存在 EXE 同目录的 settings.json，软件为便携式程序。
没有开机启动、联网、账号登录或后台下载功能。
损坏的设置文件会恢复默认值。运行异常写入同目录 error.log。
程序退出后再次打开，需要主动点击开始才播放桌面特效。

开发
源代码使用 C#、.NET 10、WPF 和 Windows 原生透明窗口，无额外第三方绘图依赖。
设置面板使用 WPF；桌面特效使用独立线程、缓存图像和原生像素缓冲区。
雪花模糊纹理在初始化时生成并缓存；动画帧只复用图像，不逐帧计算模糊。
播放桌面特效时停止面板内的重复预览，暂停或关闭特效层会释放相应绘制工作。
用 VS Code 打开 F:\DesktopWeather；推荐安装 Microsoft 的 C# 扩展。
Ctrl + Shift + B 构建；任务菜单包含运行、发布和验证任务。
终端命令：
  powershell -ExecutionPolicy Bypass -File .\Build.ps1
  powershell -ExecutionPolicy Bypass -File .\Build.ps1 -Publish
  powershell -ExecutionPolicy Bypass -File .\Build.ps1 -Test
项目专用 SDK 在 .tools\dotnet，未修改系统 PATH。
发布 EXE 自带运行环境，目标为 Windows 10/11 x64。

结构
MainWindow.xaml：设置和预览界面。
Rendering：粒子模拟、缓存图像、绘制线程与帧率统计。
OverlayWindow.cs、Interop：透明置顶窗口与鼠标穿透。
Services：屏幕管理、托盘、快捷键和设置存储。
tests：粒子边界、异常参数和设置读取检查。
--self-test <目录>：验证本软件界面与窗口属性，并生成预览图片和结果。
--benchmark <目录> smooth snow：在 4K 等当前屏幕上测量 700 颗雪花的实际帧率与帧间隔。
--benchmark <目录> smooth leaves：测量 700 片落叶的性能；测量只使用本软件图层。
--benchmark <目录> smooth petals：测量 700 片花瓣。
--benchmark <目录> smooth fireflies：测量 700 颗萤火虫。
--benchmark <目录> smooth rain：测量 700 条雨丝。

范围
覆盖普通桌面应用窗口；Windows 安全桌面、锁屏与独占全屏游戏不保证显示。
屏幕连接或分辨率变化会重建特效层；多显示器与不同缩放比例需在对应设备上验证。
高数量和大尺寸会提高绘制开销，可从每种模式的预设开始调节。
